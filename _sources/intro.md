# About this Book

This book is a collection of resources and examples to help you get started with Water Distribution System (WDS) design using Python.
It covers the basics of WDS optimal design.

It is designed to be a practical guide as part of the course CE4475910 Optimizing WDS  at [https://www.ariel.ac.il/],
providing step-by-step instructions and code snippets to help you understand the concepts and apply them in real-world scenarios.
